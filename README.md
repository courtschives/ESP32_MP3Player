This project is a simple MP3 player.

Parts used:
 1 ESP32
 1 YX5300 Serial MP3 Player Module
 1 Micro SD card
 3 Push buttons
 1 Potentiometer
 3 10K resistors
 1 on/off switch
 1 USB-C charger module
 1 2000mAh Lithium Ion battery
 Double-sided PCB board


 I first built the circuit on a breadboard, then soldered all parts to a compact PCB board.
 The MP3 Player has 3 buttons: pause/play, next song/folder and previous song/folder. 
 It also has a wheel potentiometer for volume control.
 The Serial MP3 Player module contains the audio jack for headphone or speaker plug in, as well as a micro SD card slot.
 The micro SD card contains all of the music files, organized in folders. By holding the next or prev buttons you can navigate through all of the folders and quickly pressing the buttons navigates you
 through the songs within the folders.
